ESTUDO DE CASO / PROJETO 01

ForceTrack.

Da ideia à interface: um sistema web para visualizar dados de monitoramento agrícola.

O DESAFIO

Transformar leituras em informação.

A proposta do ForceTrack é apoiar a visualização e análise de dados associados à força de tração agrícola. O sistema reúne uma interface, configuração de operações e área de monitoramento.

MINHA PARTICIPAÇÃO

Da interface à integração.

Fui responsável pela aplicação web e pela implementação da recepção das leituras via Web Serial API no teste USB, com apoio de ferramentas de IA. Meu colega desenvolveu a parte do Arduino.

DEMONSTRAÇÃO REAL

Teste com Arduino e potenciômetro

DADOS SIMULADOS

O potenciômetro simula variações do sinal e o site atualiza os valores recebidos por USB. A versão com célula de carga prevê comunicação HTTP via Wi-Fi; a medição física final ainda exige validação específica.
